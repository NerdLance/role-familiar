# Prototype scope

Role Familiar is presently an application foundation only. The preserved `prototype-assets/` directory is reserved for user-provided source assets and is intentionally not consumed by the application.

Out of scope for this baseline: the familiar interface, asset animation, progression, role analysis, job-listing analysis, AI chat, and any PixelLab runtime integration.

The starter authentication and settings flows remain available. The welcome page and authenticated dashboard use only placeholder product copy.
