# Baseline

Role Familiar is based on the official Laravel React starter kit, with built-in authentication, no teams, MySQL configuration, Pest, React, TypeScript, Inertia, Tailwind CSS, shadcn/ui, and Wayfinder.

Installed baseline package versions are recorded from the lock files after installation:

- Laravel framework 13.23.0
- PHP requirement ^8.3 (local runtime: PHP 8.5.7)
- React 19.2.8 and React DOM 19.2.8
- Inertia Laravel 3.2.1 and Inertia React 3.6.1
- Tailwind CSS 4.3.3
- Laravel Wayfinder 0.1.20
- Pest 5.0.2
- Laravel Boost 2.4.13 (development dependency)
- Laravel AI SDK 0.10.1

Boost provides Laravel, Inertia React, Pest, Tailwind CSS, and Wayfinder guidance and skills, plus its MCP configuration for Codex. The Laravel AI SDK configuration uses OpenAI and reads its text model from `ROLE_FAMILIAR_TEXT_MODEL`; no agent is implemented in this baseline.
